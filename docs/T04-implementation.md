# T04 — утверждённый план реализации

Владелец A / Codex; ветка `codex/t04-foreman-workflow`, база main `7bc2b3a`.
Источник статуса — `plans.md`. Исполнение последовательное через Superpowers executing-plans, без подагентов.

## 1. Основа и API

- Изолированная рабочая копия; React Router 7 Declarative; маршруты `/shift`, `/orders/new`, `/orders/:id` за существующей сессией.
- Совместимое расширение `/shift`: optional `area_id`, 404 для недоступного участка; `timezone` из APP_TIMEZONE; обновить C1 и генерируемые контракты.
- Мастер по умолчанию открывает смену; создание и управляющие действия доступны мастеру.

## 2. Мобильный сценарий

- Занятость, очередь и доступный активный наряд; текст вместе с цветом.
- Одна форма, назначение из карточки работника, участок из фильтра или единственного варианта; отдельный выбор оборудования; бригада с ответственным.
- По умолчанию planned/normal, срок до конца действующей смены мастера либо через час. Ввод срока в часовом поясе предприятия.
- Смена участка сбрасывает несовместимые оборудование и назначение. Сетевая ошибка сохраняет ввод; неизвестный исход повторяется с тем же неизменяемым телом и ключом; двойная отправка блокируется.
- Канбан по статусам, фильтры, страницы по 50 с total; на телефоне выбранная колонка.
- Карточка/история; reassign/cancel/reprioritize с expected_version, при 409 перечитать без автоматической команды.

## 3. Обновления

- `/api/v1/events`: сессия, точный Origin, только разрешённые event_id/type/work_order_id/version/occurred_at.
- Каждую секунду читать последние committed версии по доступным нарядам; короткая Session в thread pool; повторная проверка сессии/прав; outbox не трогать, миграция не требуется.
- HTTP обновление при событии/reconnect/focus и каждые 3 секунды; защита от устаревших ответов, очистка соединений/таймеров/данных при выходе.

## 4. Приёмка

- Vitest: форма, назначения, неопределённый исход/ключ, 409, занятость, устаревшие ответы.
- pytest/PostgreSQL: Origin/сессии/права, отдельные Session, поздний commit, rollback и authz.
- Production Playwright: выдача, два контекста, обновление <=5 секунд, прямые ссылки, reconnect, мобильный экран; сохранить auth/PWA.
- Сценарий на двух телефонах: <=60 секунд, <=6 действий с формой; каждый выбор/открытие/фокус/переход/отправка учитывается, символы клавиатуры отдельно. Эмуляция не заменяет ручной замер.
