# Семиминутное демо НарядAI

Показываем синтетический демонстрационный участок на HTTPS-стенде. Подготовленные результаты имеют явную метку; новые отчёты проверяет настоящий ИИ в прежнем общем бюджете $10. Пароли и ключи не попадают в слайды и запись. Подготовка аккаунтов — [инструкция судей](T18-judge-guide.md).

| Время | Показ |
| --- | --- |
| 0:00–0:45 | Панель мастера, очередь и карточка оборудования с QR. Переключить RU/KZ. |
| 0:45–1:30 | Создать наряд по фиксированному шаблону. Продиктовать русский текст, проверить и явно вставить его. |
| 1:30–2:15 | Исполнитель открывает назначение через PWA/привязанный Telegram, принимает и начинает работу. |
| 2:15–3:00 | Фото до/после, выполненные работы, материалы и обязательный чек-лист. |
| 3:00–4:15 | Три подготовленных примера: соответствует заявке, доработка, недостаточно доказательств. Прямо назвать их демонстрационными. |
| 4:15–5:15 | Сдать новый отчёт и показать настоящий worker. При ожидании открыть ранее сохранённый настоящий ответ с явным пояснением. Решение о приёмке принимает мастер. |
| 5:15–6:15 | История и отчёт смены, рейтинг Q/T; недоступные R/V показаны как «нет данных». |
| 6:15–7:00 | Закономерности с исходными числами и ссылками; ограничения фотопроверки и следующие производственные проверки. |

Физические телефоны и замеры ≤60с/≤6 действий, обновления ≤5с и фото ≤10с отложены. Демонстрация в браузере не засчитывается как мобильная приёмка. Неполный отчёт блокируется сервером до отправки, ИИ не закрывает наряд автоматически.

При недоступном API/туннеле используется [резервная запись](delivery/reserve.webm) с явной подписью; [презентация](delivery/presentation.pptx) содержит8слайдов. Текущие результаты и ограничения — [проверка релиза](MVP-finalization-verification.md).
