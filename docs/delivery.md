# Комплект сдачи MVP НарядAI

Актуальные статусы — [plans.md](../plans.md); фактические проверки и версия стенда — [MVP-finalization-verification.md](MVP-finalization-verification.md).

| Результат | Материал / режим |
| --- | --- |
| Основной цикл | PWA/API, роли, наряды, обязательные фото до/после, материалы, решение мастера, история и отчёты |
| Два языка интерфейса | RU/KZ, независимый русский голосовой ввод через локальный Whisper large-v3-turbo |
| Демо ИИ | Три синтетических prepared-v2 результата с видимой меткой; новые отчёты идут настоящему ИИ |
| Доступ судей | [Инструкция](T18-judge-guide.md), отдельные аккаунты; пароли передаются приватно |
| Запуск и восстановление | [Native runtime](mvp-native-runtime.md), прежний общий потолок $10 и сохранённый ledger |
| Семиминутная защита | [Сценарий](demo.md) |
| Презентация | [presentation.pptx](delivery/presentation.pptx): 8 редактируемых слайдов |
| Резервная запись | [reserve.webm](delivery/reserve.webm): 63,8с, RU/KZ, три маркированных prepared-вердикта и сохранённый настоящий ответ |

Физические телефоны и мобильные численные замеры отложены. Новый производственный фотобенчмарк, дообучение и перенос на VPS исключены из этого этапа. Казахские тексты прошли отдельное редакторское ревью ИИ; проверка носителем языка не заявляется. Производственная точность ИИ не измерена, prepared-результаты её не доказывают.

Секреты, cookies, приватные дампы, производственные фото и персональные данные в комплект не входят. Quick Tunnel требует включённого компьютера с запущенными сервисами.
