# Вход судей

Серверный режим выключен по умолчанию. Парольный вход сохраняется. При выключенном режиме оба маршрута судей возвращают 404; включение требует ровно трёх активных UUID с ролями master/worker/worker в одной изолированной prepared-v2 группе.

Подготовьте существующую группу `app.judge_demo --scenario-set prepared-v2` штатной командой, затем из `services/api` выполните:

```powershell
python -m app.judge_profiles --confirm-demo --cohort jury-2026
```

Используются настроенные `DATABASE_URL` и существующая группа. Команда принимает новый пароль только через скрытый ввод, добавляет рабочего 2 и печатает настройки без паролей. Повтор не меняет прежние пароли, пользователей, наряды, назначения или действия. Изменённые права и коллизии блокируют подготовку; legacy setup продолжает проверять только исходных двух пользователей.

Перед включением сохраните резервную копию стенда. Настройки сервера:

| Переменная | Значение |
| --- | --- |
| `JUDGE_MODE_ENABLED` | `true` для включения, по умолчанию `false` |
| `JUDGE_COHORT` | исходный `--cohort`, без суффикса `-prepared-v2` |
| `JUDGE_MASTER_USER_ID` | UUID существующего мастера группы |
| `JUDGE_WORKER_1_USER_ID` | UUID существующего рабочего группы |
| `JUDGE_WORKER_2_USER_ID` | UUID рабочего 2 из команды подготовки |

`GET /api/v1/auth/judge-profiles` возвращает `{profiles:[{code,display_name,role}]}` с кодами `master`, `worker-1`, `worker-2`. Логины, UUID и пароли в этот ответ не входят. `POST /api/v1/auth/judge-login` принимает только `{profile:code}` и возвращает существующий `AuthResponse`.

Для POST нужны существующий session cookie, `X-CSRF-Token` из `/auth/csrf` и доверенный Origin/Referer. Успешный вход отзывает прежнюю сессию и создаёт новые cookie/CSRF. Лимиты IP/аккаунта/пары общие с парольным входом. Ошибка серверной настройки возвращает 503 без раскрытия подробностей.

Это публичный демонстрационный доступ к выбранным аккаунтам: включайте режим только для изолированного судейского стенда. Права на наряды продолжают проверяться существующими серверными правилами.
